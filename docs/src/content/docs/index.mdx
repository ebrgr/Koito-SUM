## Features

<CardGrid>
	<Card title="ListenBrainz compatible" icon="puzzle">
		TuneTrail can be connected to any music server or client that allows for custom ListenBrainz URLs.
	</Card>
	<Card title="Scrobbler relay" icon="rocket">
		Automatically relay listens submitted to your TuneTrail instance to other ListenBrainz compatible servers.
	</Card>
	<Card title="Automatic data fetching" icon="download">
		TuneTrail automatically fetches data from MusicBrainz and images from Deezer and Cover Art Archive to compliment what is provided by your music server.
	</Card>
	<Card title="Themeable" icon="seti:css">
		TuneTrail ships with twelve different themes, now with support for custom themes!
	</Card>
</CardGrid>
