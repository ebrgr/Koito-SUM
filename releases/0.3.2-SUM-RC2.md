# Koito 0.3.2-SUM-RC2

Source release candidate; publication of the corresponding image/release is a separate step.

- Added per-profile ListenBrainz forwarding controls inside Settings → Administration.
- Added visible external tokens, saved/unsaved state and connection validation without saving or submitting listens.
- Saving forwarding disabled removes the saved URL/token while preserving local history.
- Administrative relay reads and tests require an administrator session; public profiles do not expose relay tokens.
- Adopted Koito `<base>-SUM-RC<number>` versioning, synchronized frontend/backend/build defaults and numeric RC update comparisons.
- Added version synchronization and parent-commit increment checks.

Back up the existing SQLite database before testing. Existing version 2 databases migrate to schema 3; no new schema migration is needed for these controls.

The intended container tag is `ghcr.io/ebrgr/koito-sum:0.3.2-SUM-RC2`.
Build locally until this tag has been published. See [deployment instructions](../DEPLOYMENT.md)
and [multiuser design](../MULTIUSER_DESIGN.en.md).
